# 版本说明

## 0.5.0

开发基线：原独立交付 0.4.1，哈希见 `validation/v041-base-hashes.json`。旧输入、分析结果和交付 ZIP 不修改。新版不合并覆盖原工程。

### 几何

- 新增 `cylinder_segmentation.py`：相邻原始法向叉积投票形成任意轴；连通垂直法向子区域调用原严格拟合，不放宽拟合误差。
- 法向/轴长可观测性额外门槛；使用完整严格共面邻面片衡量平滑邻域步长，避免邻三角形重剖分绕过防误报。
- 有界、band 间轮询，保留截断和来源映射。非穷尽，不认证召回。
- 新候选含 `segmentation_method`、父 band、提案依据、轴向可观测性及原始面追溯。

### 用途与重建安全

- 新增 `slicer_metadata.py`：安全读取标准位置 Bambu 私有配置，沿用全包 XML/元数据累计预算。
- 仅唯一直接映射；未知、缺失、重复、嵌套、跨模型冲突、证据截断 fail closed。
- 独立原始用途证据复算 builder 否决；无布尔、无私有变换应用、无 URI 跟随。
- 无 slicer 证据保留 core-only 兼容性；窄义角色完整不代表制造恢复。

### 截面与报告

- exact `ambiguous_section_event` 的两侧有限偏移证据，有界重试、不跨原始事件，不取代原失败、不解除 CAD 阻塞。
- 导出摘要使用完整证据 JSON Pointer，压缩文件保留原精度及来源。
- 报告 schema 4→5、版本 0.5.0；增加搜索非穷尽/召回未认证、事件汇总、角色证据及否决汇总。
- 聚合重建阻塞覆盖失败截面和需要复核的壳关系。

### 验证

400 项自动测试通过（原 333 + 新 67）；24 正例/12 反例新参数合成扫掠；3 作者公开真实文件、10 官方例、原用户样本完整重跑。四片已确认遗漏精确恢复；未宣称24个新设计特征。所有真实样本仍部分分析。

## 0.4.1（保留基线）

兼容读取、圆锥/球面候选、多方向截面、来源映射、预算与独立错误状态；修复浅环带误平面、内部 winding 分数舍入、空腔猜测清除阻塞、直接入口快照/覆盖等问题。原333项本地测试；没有真实 SolidWorks 验收。
