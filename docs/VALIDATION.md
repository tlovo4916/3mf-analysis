## 源码仓库与完整证据包

本页描述原交付版已保存的验证结果，不表示克隆本仓库就包含全部原始证据。本仓库保留源码、400 项自动测试、合成扫掠、JSON 验证摘要及来源指针；不分发真实输入、用户样本、旧版基线、完整 runs 或原测试日志。配套证据包的校验值和发布副本自检见 [REPOSITORY.md](REPOSITORY.md)。

### 四片遗漏

复古样本实例0、1，body0，instance-local源面13610–13978和13979–14347。每片369面，半径约1.2mm，轴长约1.387282mm，整片最大误差约0.00024217mm。新版自动候选的来源面集合与四片原诊断**精确相同**；旧版无圆柱、这些面原属 unresolved，且无平面覆盖。

24片均可用不变v0.4.1拟合器对原面子集复算接受。另20片是每实例10个约89°圆柱支持，只有几何拟合证据，未独立确认设计角色。原拟合器复算不是独立设计真值，更不是双向CAD等价。四片是2个位置×2实例，不是四类独立特征，不能得出全模型召回率。

### 失败保留

7个exact事件失败仍原样在案。495份真实方向完整证据的原exact失败记录与基线逐项相等。489份原主截面/调度/frame完全一致；复古两个主壳的6份方向因新候选引导frame而变化，明确列在 `verification.json`，不能冒称全部主样本不变。失败计数相等不证明连续截面等价。

探测使用原始顶点Z相邻事件；变换舍入可能产生极小间隔，宁可unavailable不跨越事件。小OLED的180个开放/分支截面不以偏层掩盖，源非流形问题仍保留。

### 用途

声明角色已关联2/10/20个组件，negative_part为0/1/2 occurrence。旧版已经通过core `other`阻止重建，新版增加明确切片器声明与独立否决，不应说旧版会自动把负体积建成材料。

不求并/差、不应用私有assembly或part矩阵。合并网格的体积/截面不是最终打印材料；所有分析仍指保留core leaf geometry。

## 完整性检查与复现

`validation/verify_generalization.py` 已核对：

- v0.4.1基线哈希不变；14个case的生产源码一致，新增集成测试不改运行算法。
- 52对NPZ数组与重新读取的原3MF完全一致；所有壳源面完整分区，候选与父band来源合法。
- 738份完整gzip JSON哈希/解析/摘要链接；探测身份、delta、边界与原失败引用。
- 四片精确来源恢复；24片用原严格拟合器重算。
- 400项套件日志、36个合成扫掠结果。

以下全量核验命令仅在**完整证据包根目录**运行，不适用于缺少原始输入和基线的纯源码克隆；最后的合成参数扫掠可在两者中执行：

```sh
python validation/verify_generalization.py
python validation/run_corpus_case.py 03-oled-retro inputs/real/03-oled-retro.3mf
python validation/run_corpus_case.py official-box inputs/official/box.3mf
python validation/parameter_sweep.py
```

新主流程默认写 `validation/reruns`，存在同名目录拒绝覆盖；验证脚本始终核对原 `validation/runs`。验证、扫掠会覆盖各自派生JSON，不覆盖原runs；需留存新派生证据时先复制。

## 没有验证/仍未实现

没有真实SolidWorks2024调用、原生特征树、参数修改或SLDPRT回执；没有最终材料布尔、制造设置解释、私有装配姿态恢复、通用裁剪BRep、自由曲面/NURBS、全局自交/包含认证。本版提升局部证据与安全边界，**尚不能称为可靠的通用参数化逆向工具**，也不能据这批相关样本宣称适配多数出口软件。
